轻量、简约的桌面侧边栏启动器。把图标收进屏幕左右两侧的抽屉里，鼠标贴边滑出，点一下就启动。

**单文件 · 零依赖 · 约 62 KB · 免安装 · 只用系统自带的 `csc.exe` 就能编译**

> **面向使用者的完整说明：[使用说明.md](使用说明.md)**（安装、图标操作、滚动、托盘菜单、常见问题）

## 功能

| 功能 | 说明 |
|---|---|
| **边缘唤出** | 鼠标移动到屏幕**左/右边缘**（6px 热区）即可唤出侧边栏，移开自动收起 |
| **全屏自动挂起** | 检测到全屏应用（游戏/视频）时自动隐藏自身，全屏结束后自动恢复 |
| **截图时保持显示** | 截图工具在前台时不会被当成全屏应用，侧边栏反而保持展开，方便一起截进去 |
| **手机式分组** | 拖到另一个图标上**长按 0.6 秒**松手，即合并成"文件夹格子"，双击进入 |
| **图标换位** | 拖到另一个图标上松手（不长按）＝两者**交换位置**，顺序存入配置 |
| **双击打开** | 单击只选中，**双击**图标才启动程序（避免误触），分组同样双击进入 |
| **图标与分组可混排** | 顶层是一个统一顺序表：把**分组**拖到任意图标上即可互换位置，图标↔图标、图标↔分组、分组↔分组都支持 |
| **拖拽时自动滚动** | 拖动图标时鼠标贴住上/下边缘，面板会自动滚动，方便拖到看不见的位置 |
| **滚动** | 三种方式：滚轮 / 鼠标贴住面板上边缘或下边缘自动滚 / 点右上 ▲、右下 ▼ 翻页 |
| **添加文件/文件夹/系统位置** | 「+ 添加」支持多选快捷方式、文件夹，以及此电脑 / 控制面板 / 回收站 / 用户文件夹 / 网络 |
| **托盘常驻** | 图标大小、暂停边缘响应、重扫桌面、开机自启、查看日志、退出 |
| **高 DPI 适配** | 按系统缩放自动放大，分辨率/缩放变化后自动重排 |

## 使用

1. 双击 `dist\DesktopDock.exe`
2. 首次运行会自动扫描桌面（用户桌面 + 公共桌面）里所有 `.lnk` / `.url` / `.exe`，生成 `dist\config.json`
3. 鼠标移到屏幕左边缘 → 侧边栏滑出 → 点击图标即可启动程序
4. **排序 / 合并图标**：按住图标拖到另一个图标上**直接松手 = 交换位置**；按住**停留约 0.6 秒**（target 出现蓝色高亮边框）再松手 = 合并为新分组；拖到已有分组格子上 = 加入该分组
5. **右键格子**：打开 / 打开所在位置 / 重命名 / 移出分组 / 删除；分组格子还有重命名、解散

## 配置（`config.json`，与 exe 同目录）

```jsonc
{
  "HotEdgeWidth": 6,          // 边缘热区宽度（像素，缩放后）
  "PanelWidth": 330,          // 面板宽度
  "CellSize": 96,             // 格子大小（图标大小 = 格子的 56%）
  "Gap": 12,                  // 格子间距
  "PanelOpacity": 0.97,       // 面板不透明度

  // 顶层顺序：图标与分组混排，可拖动调整
  // "i:<Id>" = 普通图标，"g:<分组名>" = 分组格子
  "Order": ["i:k000", "g:开发工具", "i:k001"],

  "Items": [
    { "Id": "k000", "Name": "微信", "Path": "C:\\Users\\Public\\Desktop\\微信.lnk", "Group": "" },
    { "Id": "k001", "Name": "Edge", "Path": "C:\\...\\Microsoft Edge.lnk", "Group": "开发工具" },
    { "Id": "k002", "Name": "此电脑", "Path": "shell:MyComputerFolder", "Group": "" }
  ]
}
```

- `Group` 为空表示顶层；相同 `Group` 的名字会自动合并成一个分组格子
- `Id` 是拖拽排序用的稳定标识，**不要手改或删除**
- `Path` 支持三种：文件/快捷方式、文件夹、`shell:` 命名空间（此电脑、控制面板等）
- 旧字段 `HideDesktopIcons` 已废弃（隐藏桌面图标功能已移除），留着也不会生效

改完配置后在托盘菜单点「重新加载配置」即可，无需重启。

## 开机自启

托盘菜单 → 勾选「开机自启」（写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，不需要管理员权限）。

## 重新编译

双击 `build.bat` 即可（只用 Windows 自带的 `csc.exe`，无需安装 .NET SDK）。

## 架构

```
src/
  Program.cs      入口、DPI 适配、单实例、--selftest 自检
  Native.cs       Win32 调用、桌面图标控制、全屏检测
  Config.cs       配置模型、JSON 读写、桌面扫描
  Ui.cs           缩放/配色/圆角/图标缓存
  EdgeZone.cs     边缘触发热区窗口
  DockPanel.cs    滑出面板 + 格子画布（绘制/命中/拖拽合并/右键菜单）
  DockManager.cs  托盘、定时器、全屏挂起、多屏编排
```

## 已知限制 / 注意

- **不要移动或重命名程序文件夹**：开机自启记录的是 exe 的绝对路径，挪动后会静默失效（从新位置启动一次、重新勾选即可）。
- 全屏检测采用「前台窗口矩形覆盖整个显示器」的判定，最大化窗口（露出任务栏）不算全屏；截图工具的选框层会被识别并让路。
- 顶层顺序存在 `config.json` 的 `Order` 字段里，图标用 `Id` 引用；手改配置时不要删 `Id`，否则该项会被当成新项目追加到末尾。
- 关机/强杀进程不会执行退出清理，但程序不写注册表（除开机自启）、不在系统目录留文件，直接删文件夹即可卸载。
